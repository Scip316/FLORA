# T1 — Food Assessment and Product Substitution

Python pipeline with two tasks: Food Assessment evaluates potential human-health effects of known growing inputs; Product Substitution compares replacement fertilisers, pesticides and other farming inputs for lower documented health risks while maintaining farming effectiveness and explaining trade-offs. Supported findings inform T2's Crop Rotation Planning.

Designed to run from the terminal with Excel inputs.
